# MiniEverything

基于 C++20 和 SQLite 的 Windows 文件快速查找学习项目，重点练习树结构、数据库索引、并发和性能优化。

## 项目状态

当前处于规划阶段，尚未实现扫描、搜索或桌面界面。

## 技术方向

- C++20、CMake、SQLite。
- 先实现命令行工具，后续接入桌面界面。
- 邻接表维护目录树，SQLite 持久化文件元数据。
- 先建立正确性与性能基线，再优化批量写入、扫描和内存搜索索引。
- 后续研究 Windows 文件变化监听、NTFS MFT 枚举与 USN 日志，并保留普通目录扫描路径。

| 版本 | 目标 |

以上版本是计划，不代表已经发布。

## 版本管理

- `main` 保存经过验证的开发成果。
- 使用 `feat/*` 和 `fix/*` 分支开发，测试后推送远程并合并。
- 阶段验收后创建并推送版本标签。
- 提交源码、测试、数据库迁移脚本和基准报告；不提交实际文件索引数据库、日志、本机配置及构建产物。

## 第一阶段验收目标

扫描一个指定目录，将文件及目录父子关系保存到 SQLite，通过命令行查询文件名，并用自动化测试验证结果。
