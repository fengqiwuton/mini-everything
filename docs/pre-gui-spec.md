# GUI 前的命令行与核心服务

2026-10-14，用户授权自主推进到 GUI 之前，完成大致的文件搜索与管理功能。沿用 C++20、SQLite、Windows 优先及 Linux 核心验证，保留每个函数前的中文说明与文件职责文档。

## 可交付范围

1. 高级搜索：字面包含/精确/前缀匹配、名称或路径、文件/目录、扩展名、根/子树范围、大小/Unix 时间上下界、排序、分页。默认 TSV 行为兼容旧搜索，可选 JSON 与节点 ID 输出供脚本/GUI 使用。
2. 目录服务：节点详情、直接子项、祖先链、有限深度/条数的树、子树文件/目录/字节统计。离线索引仍可查询，节点不存在或参数非法会明确报错。
3. 索引管理：根列表、总体统计、仅删除数据库内某根记录的 forget、数据库与树关系健康检查；根目录以持久化 root ID 区分，节点 ID 与 root ID 分开输出。
4. 扫描维护：进度回调与 Ctrl+C 取消；取消、回调故障和 SQL 故障在提交前回滚。增量校准复用未变化路径的节点 ID，仅写变化行，用连接临时表记录本次出现节点并删除失效记录。
5. refresh 对注册根做增量校准；watch 在 Windows 用 ReadDirectoryChangesW 标脏，合并事件后做校准；其他平台以轮询校准回退。监听启动先建立变化捕获，再校准；缓冲溢出也触发校准。每次校准仍遍历元数据，不宣称逐事件即时更新百万文件。

“文件管理”本轮实现为索引管理、目录浏览、文件定位及维护；不执行用户真实文件的移动、删除或重命名。GUI、内容全文搜索、NTFS MFT/USN 特殊权限加速不属于本轮基础验收。

## 不变量

- SQLite application_id 与 schema 1 不变；旧版本仍可读取新增功能生成的数据库。
- 默认 search 的 5 列 TSV 不变；显式 --show-ids 后为 7 列，JSON 另行选择。
- 数据库必须在扫描范围外；保持链接跳过、数据库硬链接保护、重叠根拒绝和严格读取失败回滚。
- 增量模式的稳定 ID 只适用于保留相同规范路径的节点；路径移动或重建索引可改变 ID。
- watch/refresh 设置 expected_root_id，在写事务内确认根仍注册，防止其他命令 forget 后监听重新添加该根。
- 读操作使用只读连接与同一读事务；forget 在一个写事务内删除该根节点及 roots 行。
- tree 最大深度 1000、最多 10000 行；ancestor 检测父链循环；所有数值、排序字段与枚举均校验，用户文本只经参数绑定进入 SQL。
- CLI 退出码 0 成功、1 操作失败、2 参数错误、130 取消；进度与监听诊断到 stderr，结构化结果到 stdout。
- 新功能验证仅用临时夹具，用户实际索引不迁移、不写入，开发不扫描 D:/Users。

## 核心模块边界

query.hpp/query.cpp 负责高级搜索和目录查询；catalog.hpp/catalog.cpp 负责根列表、统计、forget 与健康检查；现有 index.hpp/index.cpp 负责进度、取消和增量扫描；watch.hpp/watch.cpp 负责事件/轮询维护；main.cpp 适配参数、文本/JSON 输出和信号。

共用 src/read_index.hpp 提供 detail::require_index(Database&) 与只读事务包装 detail::ReadIndex，公开成员 db 供模块查询。它校验应用/版本标记，不替代完整健康检查。

## 验收

测试 SQL 特殊字符、Unicode、边界分页、过滤组合、空/多根索引、深树、非法节点、错误格式、外键/父链异常、forget 回滚与磁盘文件保留、增量无变化/新增/修改/删除/类型变化、取消和回调故障、监听更新及退出。Debug/Release、本机 Windows 与远程 MSVC/Linux 均需通过；完整基准确认输出/元数据一致，再归档版本。
