# v0.1 实施记录

用户已确认 C++、SQLite、命令行优先，并授权开始第一版开发和远程版本管理。

## 范围与约定

- C++20 / CMake；固定 SQLite 源码版本和下载校验值。
- `scan <directory> --db <file>`：迭代 DFS，记录目录父子关系、UTF-8 名称、完整路径、大小、修改时间。
- `search <text> --db <file> [--ext pdf] [--limit 100]`：字面子串搜索，ASCII 大小写不敏感，稳定排序。
- 单次根目录扫描在事务内替换该根索引；任何读取/写入失败回滚，保留旧索引。进程强制退出由 SQLite 回滚。
- 跳过符号链接及 Windows 重解析点；拒绝重叠根目录和位于扫描范围内的索引库，避免循环及索引自身。
- 第一版不提供实时监听、GUI、NTFS 加速、全文搜索、全 Unicode 大小写折叠或一致的文件系统快照。
- 显式指定数据库位置；搜索只读打开已有索引，不隐式创建数据库。

## 决策

- 复用当前干净工作目录，在 `feat/cli-v1` 开发，避免额外 worktree。
- v0.1 采用整根事务刷新，扫描失败即回滚；局部容错、分批发布与更强校准留给后续版本。
- 扫描性能以正确性基线为准，暂不承诺百万级性能。

## 验证记录

- 初始空实现：13 项测试中 11 项因缺失扫描或 CLI 失败；其余两项仅验证拒绝输入。
- 完成核心实现后：初始 13 项测试全部通过。
- 独立审查发现 Windows 8.3 别名和数据库硬链接两个问题；分别添加回归测试并观察失败后修复。
- 扩展后的 16 项测试覆盖目录联接循环、中文 CLI、大小写及短名别名、硬链接回滚和格式版本拒绝。
- Debug、Release 及 PowerShell 5.1 路径集成测试在本机验证。远程 CI 另行验证 MSVC 和 Linux。
- 构建脚本兼容本机 CMake 证书缺失情形，使用系统证书下载并验证 SHA256；未降低 TLS 安全设置。
- GCC 14 Release 编译 SQLite 3.53.4 时第三方源文件产生一条 `-Wstringop-overread` 警告；项目源文件无编译警告，未修改第三方源码或隐藏该警告。
